🎓 Learnify — Online Learning Landing Page

📖 About

Learnify is a modern landing page design for an online learning platform, created in Figma. It helps learners discover courses, develop new skills, and learn at their own pace.

🎨 Design Tool

- Tool: Figma
- Project Type: Landing Page UI/UX Design
- Category: Online Education
- Design Style: Modern, clean, and user-friendly

✨ Design Features

- Navigation Bar: Learnify branding, navigation links, and a Get Started button.
- Hero Section: A headline introducing the learning platform and a Start Learning button.
- Why Choose Learnify: Feature cards highlighting expert instructors, flexible learning, and practical projects.
- Popular Courses: Course cards for Web Development, UI/UX Design, and Data Science.
- Contact Section: Contact information for the platform.
- Footer: Brand description, navigation links, and copyright information.

🧩 Design Components

- Auto Layout applied to feature cards.
- Reusable components created for the feature cards.
- Consistent typography, spacing, and visual styling.
